⏱️ Stopwatch App

A sleek and responsive **Stopwatch App** built with **HTML**, **CSS**, and **JavaScript**. Track time with start, stop, and reset functionality — all from your browser.

---

## 🌟 Features

- ▶️ Start, ⏹️ Stop, and 🔁 Reset buttons
- ⏳ Display minutes, seconds, and milliseconds
- 🧠 Vanilla JavaScript — no frameworks
- 💻 Fully responsive layout
- 🎨 Clean and minimal UI design

---

## 🛠️ Tech Stack

- **HTML** – Markup and layout
- **CSS** – Styling and responsiveness
- **JavaScript** – Core stopwatch logic
